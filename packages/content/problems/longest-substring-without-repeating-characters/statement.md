Return the length of the longest **substring** (contiguous block of characters) of `s` in which no character appears more than once.

**Examples**

```
s = "pwwkew"       ->   3      "wke"; note "pwke" is not contiguous
s = "abba"         ->   2      "ab" or "ba"
s = "dvdf"         ->   3      "vdf"
s = ""             ->   0
```

**Constraints**

- `0 <= s.length <= 10^5`
- `s` consists of printable ASCII characters (codes 32 to 126), including spaces and punctuation.
